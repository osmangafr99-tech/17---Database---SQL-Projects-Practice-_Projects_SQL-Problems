## 💡 Advanced SQL Problem Solving & Query Solutions (`Solve the questions/`)

This section serves as a comprehensive problem-solving log, featuring **54+ structured SQL scripts** and solutions addressing complex data manipulation and querying challenges. Each text file contains optimized queries tested against real-world database scenarios[cite: 16, 17].

### 🔍 Key Concepts & Query Categories Covered:

* **Views & Schema Abstraction:** Creating and managing master views for simplified data access (`Problem 1`)[cite: 16].
* **Aggregations & Statistical Analysis:** Grouping, counting, ordering descending/ascending, and calculating minimum, maximum, and average metrics (e.g., Engine CC analysis in `Problems 33-38`)[cite: 16, 17].
* **Conditional Logic & Pattern Matching:** Utilizing wildcard filtering (`LIKE 'B%'`, `LIKE '%W'`), checking ranges (`BETWEEN 1950 AND 2000`), and handling unspecified/null data (`IS NULL` / handling missing attributes)[cite: 16, 17].
* **Subqueries & Top-N Analysis:** Extracting top records (e.g., getting the top 3 engine CC or manufacturers, filtering results based on aggregated totals using `HAVING` and `TOP` clauses)[cite: 16, 17].
* **Self-Joins & Hierarchical Data:** Managing employee-manager relationships, handling missing managers gracefully, and tracking hierarchical data structures (`Problems 51-54`)[cite: 17].
* **Data Transformation & Computed Columns:** Adding custom columns dynamically to calculate ages, categorize door counts into words, and compute specific taxes based on attributes (`Problems 30-32, 42`)[cite: 16, 17].
